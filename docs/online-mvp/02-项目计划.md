## 1. 项目目标

在 7 个自然日内完成联网 MVP 的需求基线、设计、编码、测试与可部署版本，满足：

1. 单人 + 3 机器人、双真人 + 2 机器人两种玩法；
2. 服务端权威、视角隔离、非法动作零状态变更；
3. 断线重连、超时托管、多窗口互踢；
4. MP 与贴点制计分、逐副记录、整场落盘与复盘；
5. `/solo` 既有功能与测试不回归。

## 8. 沟通与变更管理

- **日常**：任务清单驱动；每完成一个工作包更新 `tasks.md` 与评审记录。
- **变更**：任何范围/协议/计分口径变更必须提交 CR，记录影响面、测试与文档更新。
- **评审**：需求、设计、代码、测试四类评审；结论写入 `05-评审记录.md`。
- **发布**：技术负责人签署发布门禁；发布后保留回滚点。

## 9. 发布计划

1. `npm ci`
2. `npm test` + `npm run typecheck` + `npm run typecheck:server` + `npm run build`
3. 手工冒烟：单人 12 副、双人 12 副、断线重连、超时托管、历史查询
4. `npm start`，健康检查 `GET /api/health`
5. 观察 30 分钟：连接数、错误日志、房间推进
6. 回滚：保留上一版本构建产物与数据目录；异常时切回上一版本
