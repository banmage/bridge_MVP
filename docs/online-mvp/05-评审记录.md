## 1. 评审流程

```text
需求评审 → 设计评审 → 编码实现 → 代码评审 → 测试评审 → 发布评审
   │           │            │           │           │
   └─ 需求基线 └─ 设计基线  └─ CR 记录  └─ 缺陷修复 └─ 门禁签署
```

每次评审输出：结论（通过/有条件通过/不通过）、问题清单、责任人、关闭状态。
所有范围/协议/计分变更必须登记 CR。
